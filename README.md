# Bounty of One - APWorld

Bounty Of One Implementation for the Multi-Game-Randomizer [Archipelago](https://github.com/ArchipelagoMW/Archipelago).
Both APWorld and Client are included in this repo.

## Current Status
**Status**: Work in Progress

:warning: The APWorld is functional and can generate Archipelago MultiWorlds. However, the Bounty of One Client is still in development and is required to play a randomized game. :warning:

### APWorld

**Implemented**:
- Region generation
- Location generation
- Item generation
- Game logic and access rules
- Configurable world options

**Planned**:
- Balance locations and items
- Add shop locations
- Add achievement locations
- Enable enemy and boss randomization
- Add DLC Support
- Add Co-Op Support
- Implement Nightmare Escape

### Client

**Planned**:
- Connect to Archipelago
- Receive Items and apply them
- Send Locations

## Requirements
- Archipelago Launcher: [GitHub](https://github.com/ArchipelagoMW/Archipelago/releases/latest)
- Bounty of One: [Steam](https://store.steampowered.com/app/1968730/Bounty_of_One/)
- Bounty of One Client: WIP
- APWorld: [GitHub](https://github.com/Tooobiii/bounty-of-one-apworld/releases/latest)

## Installation
1. Install [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases/latest)
2. Download the latest APWorld from [Releases](https://github.com/Tooobiii/bounty-of-one-apworld/releases/latest)
3. Open the downloaded *.apworld* file with Archipelago or place it in the *custom_worlds* folder of your Archipelago installation

The world can be configured through the YAML options.
